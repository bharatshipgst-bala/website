How it works

  1. InstallMerchant installs the app via Shopify OAuth.
  2. Set upEnter GSTIN, business address, pickup pincode and Delhivery / Blue Dart API keys.
  3. Order createdThe app receives the order from the Shopify Admin API.
  4. InvoiceGST engine calculates CGST/SGST or IGST and generates a PDF invoice.
  5. ShipCheck pincode serviceability, book the courier, generate AWB & label.
  6. TrackTracking number is synced to Shopify and the order is fulfilled.
